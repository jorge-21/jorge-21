## Featured work

### [Rural Credit Policy Analytics](https://github.com/jorge-21/finagro)

An end-to-end analysis of how Finagro lending may affect Colombia’s benchmark lending rate and the regulatory interest-rate ceiling.

The project combines large-scale public microdata from Finagro and the Colombian Financial Superintendency with:

* Reproducible ingestion and consolidation pipelines
* Weighted benchmark-rate replication and validation
* Market-share and interest-rate gap analysis
* Shift-share decomposition
* Newey–West regressions with macroeconomic controls
* Translation of analytical results into policy-relevant conclusions

**Tools:** Python, pandas, Polars, statistical modeling, Google Colab, public-data APIs
